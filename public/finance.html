⚡ Pintasan HP (Action Button & Siri)

Catat pengeluaran instan hanya dalam 1 detik via tombol Action Button iPhone, perintah suara Siri, atau widget di layar utama Android tanpa perlu buka WhatsApp/aplikasi apa pun!

🍎 Panduan Pasang di iPhone (Aplikasi Shortcuts / Pintasan):
  1. Buka aplikasi bawaan Shortcuts (Pintasan) di iPhone kamu > tekan tanda + (Buat Pintasan Baru).
  2. Beri nama pintasan, misalnya: "Catat Pengeluaran".
  3. Tambahkan Aksi 1: Cari "Ask for Input (Minta Masukan)" (Pertanyaan: "Catat apa?", Jenis: Teks).
  4. Tambahkan Aksi 2: Cari "Get Contents of URL (Dapatkan Konten URL)":
    • URL: Tempelkan Webhook URL di atas.
    • Metode (Method): POST.
    • Request Body: Pilih JSON > Tambahkan Field text bernilai Provided Input.
  5. Tambahkan Aksi 3: Cari "Show Notification (Tampilkan Pemberitahuan)" atau "Speak Text" (ambil teks balasan dari hasil server).
  6. Selesai! Sekarang kamu bisa panggil "Hei Siri, Catat Pengeluaran" atau pasang di Action Button iPhone 15/16 Pro via Settings > Action Button > Shortcut!
🤖 Panduan Pasang di Android (HTTP Shortcuts / Tasker):
  1. Install aplikasi gratis HTTP Shortcuts dari Google Play Store / F-Droid.
  2. Buat Shortcut baru > pilih Method: POST > Tempelkan Webhook URL di atas.
  3. Di tab Request Body: pilih JSON, isi dengan {"text": "{input}"}.
  4. Di tab Variables: buat variabel input dengan tipe Text input prompt (pesan: "Catat pengeluaran apa?").
  5. Simpan, lalu tambahkan Widget Shortcut tersebut ke Layar Utama (Home Screen) Android!
